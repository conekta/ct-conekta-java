

# ApplePaySessionResponse

Apple Pay merchant session returned by Apple. Pass this object as-is to `session.completeMerchantValidation` in the browser. 

## Properties

| Name | Type | Description | Notes |
|------------ | ------------- | ------------- | -------------|
|**epochTimestamp** | **Long** | Date and time, in milliseconds since epoch, when the session was created. |  |
|**expiresAt** | **Long** | Date and time, in milliseconds since epoch, when the session expires. |  |
|**merchantSessionIdentifier** | **String** | Unique identifier of the merchant session generated by Apple. |  |
|**nonce** | **String** | Single-use value used by Apple to verify the session. |  |
|**merchantIdentifier** | **String** | Hashed Apple Pay merchant identifier the session was validated with. |  |
|**domainName** | **String** | Domain the session was validated for. |  |
|**displayName** | **String** | Merchant name shown in the Apple Pay sheet. |  |
|**signature** | **String** | Apple signature of the session, in hexadecimal format. |  |
|**operationalAnalyticsIdentifier** | **String** | Identifier used by Apple for analytics purposes. |  [optional] |
|**retries** | **Integer** | Number of times the session validation has been retried. |  [optional] |
|**pspId** | **String** | Payment service provider identifier assigned by Apple. |  [optional] |
